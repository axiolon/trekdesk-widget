| Version | Supported          |
| ------- | ------------------ |
| v1.x    | :white_check_mark: |

## Reporting a Vulnerability

We take the security of our users and their data seriously. If you believe you have found a security vulnerability in the TrekDesk AI widget, please report it to us as soon as possible.

### How to report

Please do **not** open a public GitHub issue. Instead, send an email to:
**axioloninc@gmail.com**

In your report, please include:
- A description of the vulnerability.
- Steps to reproduce (proof of concept).
- The potential impact.

### Our Commitment

If you report a vulnerability, we will:
1. Acknowledge receipt within 48 hours.
2. Provide a timeline for a fix.
3. Notify you once the issue is resolved.
4. Credit you in our changelog (if desired) once the fix is public.

Thank you for helping keep TrekDesk AI secure!
